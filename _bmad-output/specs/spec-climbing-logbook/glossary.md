# Glossary — climbing-logbook

- **Area** — a climbing area/crag. Top of the hierarchy; contains one or more sectors.
- **Sector** — a subdivision of an area (a cluster of climbs); contains one or more climbs.
- **Climb** — a single route or boulder within a sector. `kind` is `route` or `boulder`.
- **Route** — a climb kind climbed with rope and gear.
- **Boulder** — a climb kind climbed ropeless, low to the ground.
- **Difficulty** — a grade on the climb, from a constrained, ordered French/Fontainebleau scale (4a through 9c+), used uniformly for both routes and boulders.
- **Tag** — a free-form style descriptor attached to a climb (e.g. crimpy, slab, powerful, sketchy, endurance). Many-to-many with climbs.
- **Log entry** — one user's record of attempting/sending a specific climb. Per-user-owned.
- **Flash** — sent a climb on the first attempt, with prior knowledge of the moves (beta).
- **Redpoint** — sent a climb successfully after prior attempts/practice.
- **Project** — a climb currently being worked on, not yet sent.
- **Todo** — a climb spotted but not yet attempted.
- **Media** — a photo or video attached to an area, sector, climb, or log entry.
- **Group** — the boundary a set of areas (and everything under them) belongs to; a set of users who share access to those areas. An instance can host several groups side by side, each isolated from the others; a user belongs to exactly one.
- **Invite code** — a group's single standing join code; anyone with it can register directly into that group. Regenerable by any member, which invalidates the old code.
